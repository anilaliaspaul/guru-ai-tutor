# Changelog

All notable changes are documented here. GURU was not previously published publicly; therefore, the complete initial public feature set is released as **v1.0**. Earlier internal development labels are intentionally not carried forward as public releases.

## 1.0 – Initial public release

- Introduced GURU – Your Personal AI Learning Mentor, with the tagline “Learn. Practise. Revise. Master.”
- Added a reusable, subject-independent teaching framework with six complementary teaching methods.
- Added personalised learning-roadmap creation, diagnostic questions, practical exercises, and a mastery rubric.
- Added learner intake for subject, goal, target date, daily study-time target, teaching language, teaching mode, study-calendar preferences, and lesson-preparation/notification preferences.
- Added optional **Other special instructions** for course-specific requirements, dated syllabus reviews, constraints, and learner preferences.
- Added mandatory revision after every module, cumulative progress tests every seven calendar days, and a comprehensive final assessment.
- Added missed-work recovery, learner-controlled sessions, and checkpoint-based continuation.
- Added scheduling workflows that distinguish lesson preparation, study appointments, calendar events, and notifications, subject to host integrations.
- Added dated syllabus and exam-model review rules requiring authoritative verification before changing course content.
- Added Claude Code and ChatGPT Codex skill discovery layouts, OpenAI metadata, installation documentation, roadmap, and MIT licence.
- Included GURU branding assets.
